# Как запустить игру в интернете

Понадобятся три бесплатных сервиса, и во все можно войти через GitHub:

- **GitHub** хранит файлы игры;
- **Turso** — база данных, где лежат игроки и результаты;
- **Vercel** — сервер, который показывает игру по ссылке.

Всё делается один раз, примерно за 20 минут. Программировать не нужно.

> Кнопки на сайтах иногда немного меняют названия. Если что-то называется чуть иначе, ищите похожее по смыслу.

---

## Часть 1. Файлы на GitHub (5 минут)

1. На github.com нажмите **+ → New repository**.
2. Имя, например, `lab`. Можно выбрать **Private**, тогда код никто не увидит. Нажмите **Create repository**.
3. Нажмите ссылку **uploading an existing file**.
4. Откройте папку с игрой (ту, где лежат `package.json`, `vercel.json` и папки `api`, `public`, `server`), выделите всё внутри (Ctrl+A) и перетащите в окно GitHub.
   Перетаскивайте содержимое папки, а не саму папку.
5. Дождитесь загрузки и нажмите **Commit changes**.

## Часть 2. База данных Turso (5 минут)

1. Откройте **turso.tech** → **Sign up** → войдите через GitHub. Тариф **Free**.
2. **Create Database**: имя `lab`, регион ближайший (например, Frankfurt).
3. Откройте созданную базу и скопируйте её адрес. Он выглядит так: `libsql://lab-ваш-логин.turso.io`. Сохраните его в заметки.
4. Нажмите **Create Token** (или **Generate Token**). Срок действия — **Never**, доступ — **Read & Write**. Скопируйте токен (длинная строка) и тоже сохраните.
   Токен показывают один раз. Если не успели скопировать, создайте новый.

## Часть 3. Сервер Vercel (5 минут)

1. Откройте **vercel.com** → **Sign Up** → тариф **Hobby** → войдите через GitHub.
2. **Add New… → Project** → найдите репозиторий `lab` → **Import**.
   Если его нет в списке, нажмите **Adjust GitHub App Permissions** и разрешите Vercel доступ к репозиторию.
3. Framework Preset — **Other**. Остальные настройки сборки не трогайте.
4. Откройте раздел **Environment Variables** и добавьте три строки:

   | Name | Value |
   |---|---|
   | `TURSO_DATABASE_URL` | адрес базы из части 2 (`libsql://…`) |
   | `TURSO_AUTH_TOKEN` | токен из части 2 |
   | `ADMIN_PASSWORD` | придумайте пароль для кабинета |

5. Нажмите **Deploy** и подождите минуту. Появится ссылка вида `https://lab-xxxx.vercel.app`.

### Красивый адрес без вашего имени

В Vercel откройте проект → **Settings → Domains**. Там можно заменить адрес на свободное имя, например `eks-lab.vercel.app`.

## Часть 4. Проверка (2 минуты)

1. Откройте `https://ваш-адрес.vercel.app/api/health`. Должно быть видно `"ok":true`, `"db":"turso"` и `"adminConfigured":true`.
2. Откройте `https://ваш-адрес.vercel.app/#/admin` и войдите с паролем из `ADMIN_PASSWORD`.
3. В кабинете скопируйте **Ссылку для группы** и отправьте одногруппникам.

---

## Как пользоваться

- **Игра.** Пролог, 4 главы, 17 случайных дел и главное расследование. За каждую главу, где решено хотя бы половина дел, игрок получает улику. В конце он называет виновного.
- **Одна попытка.** Если игрок закрыл вкладку, он продолжит с того же места, даже с другого телефона. Время на дело при этом не останавливается.
- **Кабинет** (`/#/admin`) обновляется сам каждые 15 секунд. Там видно:
  - кто сейчас играет и на каком деле;
  - лучшие результаты и звания;
  - какие темы и дела даются труднее всего.

  Отсюда же можно дать «+1 попытку» одному игроку или всем, удалить ошибочную попытку и скачать CSV для Excel.
- **Подвести итоги.** Пьедестал для проектора: места открываются по одному, с барабанной дробью.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| «Лаборатория недоступна» | Откройте `/api/health` и прочитайте ошибку. Чаще всего неверно скопирован адрес или токен Turso. Исправьте его в Vercel → Settings → Environment Variables, затем **Deployments → ⋯ → Redeploy**. |
| «Пароль руководителя не задан» | Добавьте `ADMIN_PASSWORD` в Environment Variables и сделайте Redeploy. |
| Нужно сменить пароль | Измените `ADMIN_PASSWORD` в Vercel и сделайте Redeploy. Затем в кабинете нажмите «Выйти на всех устройствах». |
| «Слишком много неверных попыток» | Подождите 10 минут. |
| Исправить вопрос | На GitHub откройте `server/data/cases.js` → карандаш ✏ → правка → Commit. Vercel обновит сайт сам за минуту. Правильный ответ всегда пишется первым. |
