# Как запустить игру в интернете

Понадобятся три бесплатных сервиса, и во все можно войти через GitHub:

- **GitHub** хранит файлы игры;
- **Turso** — база данных, где лежат игроки и результаты;
- **сервер**, который показывает игру по ссылке: Netlify, Render или Vercel, на выбор.

Всё делается один раз, примерно за 20 минут. Программировать не нужно.

> Кнопки на сайтах иногда немного меняют названия. Если что-то называется чуть иначе, ищите похожее по смыслу.

---

## Часть 1. Файлы на GitHub (5 минут)

1. На github.com нажмите **+ → New repository**.
2. Имя, например, `lab`. Можно выбрать **Private**, тогда код никто не увидит. Нажмите **Create repository**.
3. Нажмите ссылку **uploading an existing file**.
4. Откройте папку с игрой (ту, где лежат `package.json`, `vercel.json` и папки `api`, `public`, `server`), выделите всё внутри (Ctrl+A) и перетащите в окно GitHub.
   Перетаскивайте содержимое папки, а не саму папку.
5. Дождитесь загрузки и нажмите **Commit changes**.

## Часть 2. База данных Turso (5 минут)

1. Откройте **turso.tech** → **Sign up** → войдите через GitHub. Тариф **Free**.
2. **Create Database**: имя `lab`, регион ближайший (например, Frankfurt).
3. Откройте созданную базу и скопируйте её адрес. Он выглядит так: `libsql://lab-ваш-логин.turso.io`. Сохраните его в заметки.
4. Нажмите **Create Token** (или **Generate Token**). Срок действия — **Never**, доступ — **Read & Write**. Скопируйте токен (длинная строка) и тоже сохраните.
   Токен показывают один раз. Если не успели скопировать, создайте новый.

## Часть 3. Сервер — выберите один вариант (5 минут)

Игра одинаково работает на любом из трёх сервисов. Если один не пускает при регистрации, берите другой.

| | Netlify (рекомендую) | Render | Vercel |
|---|---|---|---|
| Скорость | быстро всегда | после 15 минут без посетителей засыпает, первое открытие ~1 минута | быстро всегда |
| Регистрация | через GitHub | через GitHub, без карты | может попросить телефон |
| Адрес | `имя.netlify.app` | `имя.onrender.com` | `имя.vercel.app` |

Во всех вариантах нужны одни и те же **три переменные**:

| Имя (Key) | Значение (Value) |
|---|---|
| `TURSO_DATABASE_URL` | адрес базы из части 2 (`libsql://…`) |
| `TURSO_AUTH_TOKEN` | токен из части 2 |
| `ADMIN_PASSWORD` | придумайте пароль для кабинета |

### Вариант А. Netlify

1. Откройте **app.netlify.com** → **Sign up** → **GitHub**. Тариф **Free**.
2. **Add new project** (или **Add new site**) → **Import an existing project** → **GitHub** → выберите репозиторий `lab`.
   Если его нет в списке, нажмите **Configure Netlify on GitHub** и разрешите доступ к репозиторию.
3. Настройки сборки Netlify подставит сам из файла `netlify.toml`: папка публикации `public`, команда сборки пустая. Ничего не меняйте.
4. Нажмите **Add environment variables** и добавьте три переменные из таблицы выше.
5. Нажмите **Deploy** и подождите 1–2 минуты. Появится ссылка вида `https://случайное-имя.netlify.app`.
6. Чтобы сменить адрес: **Project configuration** (или Site configuration) → **Change project name**, например на `eks-lab`. Получится `eks-lab.netlify.app`.

Если переменные добавляли уже после первой публикации: **Deploys → Trigger deploy → Deploy site**.

### Вариант Б. Render

1. Откройте **render.com** → **Get Started** → **GitHub**.
2. **New + → Web Service** → выберите репозиторий `lab` → **Connect**.
3. Заполните:
   - **Runtime:** Node
   - **Build Command:** `true`
   - **Start Command:** `npm start`
   - **Instance Type:** **Free**
4. В разделе **Environment Variables** добавьте три переменные из таблицы и ещё одну: `NODE_VERSION` = `22`.
5. Нажмите **Create Web Service** и подождите 2–3 минуты. Ссылка будет вверху, вида `https://lab-xxxx.onrender.com`.

На бесплатном тарифе сервер засыпает, если его 15 минут никто не открывал. Первое открытие после этого занимает около минуты. Перед парой откройте ссылку сами за пару минут до начала, тогда у группы всё загрузится сразу.

### Вариант В. Vercel

1. **vercel.com** → **Sign Up** → **Hobby** → GitHub.
2. **Add New… → Project** → репозиторий `lab` → **Import**, Framework Preset — **Other**.
3. **Environment Variables**: три переменные из таблицы → **Deploy**.
4. Адрес меняется в **Settings → Domains**.

## Часть 4. Проверка (2 минуты)

1. Откройте `ваш-адрес/api/health`, например `https://eks-lab.netlify.app/api/health`. Должно быть видно `"ok":true`, `"db":"turso"` и `"adminConfigured":true`.
   Если там `"ok":false`, рядом написана причина, смотрите таблицу «Если что-то не так».
2. Откройте `ваш-адрес/#/admin` и войдите с паролем из `ADMIN_PASSWORD`.
3. В кабинете скопируйте **Ссылку для группы** и отправьте одногруппникам.

---

## Как пользоваться

- **Игра.** Пролог, 4 главы, 17 случайных дел и главное расследование. За каждую главу, где решено хотя бы половина дел, игрок получает улику. В конце он называет виновного.
- **Одна попытка.** Если игрок закрыл вкладку, он продолжит с того же места, даже с другого телефона. Время на дело при этом не останавливается.
- **Кабинет** (`/#/admin`) обновляется сам каждые 15 секунд. Там видно:
  - кто сейчас играет и на каком деле;
  - лучшие результаты и звания;
  - какие темы и дела даются труднее всего.

  Отсюда же можно дать «+1 попытку» одному игроку или всем, удалить ошибочную попытку и скачать CSV для Excel.
- **Подвести итоги.** Пьедестал для проектора: места открываются по одному, с барабанной дробью.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| «Лаборатория недоступна» или «Не заданы TURSO_…» | Не добавлены переменные или в них опечатка. Исправьте их в настройках сервера и перезапустите публикацию: Netlify — **Deploys → Trigger deploy**, Render — **Manual Deploy → Deploy latest commit**, Vercel — **Deployments → ⋯ → Redeploy**. |
| В `/api/health` написано `401` или `fetch failed` | Неверный токен или адрес Turso. Создайте новый токен и вставьте его заново, адрес должен начинаться с `libsql://`. |
| «Пароль руководителя не задан» | Добавьте `ADMIN_PASSWORD` в переменные и перезапустите публикацию. |
| Нужно сменить пароль | Измените `ADMIN_PASSWORD` в настройках сервера и перезапустите публикацию. Затем в кабинете нажмите «Выйти на всех устройствах». |
| На Render сайт долго открывается | Это сервер просыпается, подождите около минуты. Перед парой открывайте ссылку заранее. |
| «Слишком много неверных попыток» | Подождите 10 минут. |
| Исправить вопрос | На GitHub откройте `server/data/cases.js` → карандаш ✏ → правка → Commit. Сервер обновит сайт сам за 1–2 минуты. Правильный ответ всегда пишется первым. |
